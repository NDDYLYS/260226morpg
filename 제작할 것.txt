



오퍼 받기
유니티로 빌드한 프로그램에서, 뭔가 버그가 발생하면 console창에 뜨는 내역일 텍스트 파일로 저장했다가 파일로 달라고 할 수 있나?

가능해. 유니티로 빌드한 프로그램에서도 콘솔 로그를 자동으로 파일에 저장할 수 있어. 보통 두 가지 방법을 많이 쓴다.

1️⃣ 유니티 기본 로그 파일 사용 (가장 쉬움)
유니티 빌드 프로그램은 기본적으로 로그 파일을 자동 생성한다.
사용자에게 이 파일을 보내달라고 하면 된다.

Windows 경로
C:\Users\사용자이름\AppData\LocalLow\회사이름\게임이름\Player.log
예:

C:\Users\John\AppData\LocalLow\MyCompany\MyGame\Player.log
여기에는

Debug.Log

Debug.LogWarning

Debug.LogError

Exception

StackTrace

같은 콘솔 내용이 전부 기록된다.

📌 사용자에게 안내 예:

Win + R → %appdata% 입력
→ AppData 폴더에서 LocalLow 이동
→ 회사이름 → 게임이름 → Player.log 파일 보내주세요
2️⃣ 게임 내부에서 로그 파일 따로 저장 (추천)
사용자가 버그 발생 → 버튼 눌러서 로그파일 저장 같은 기능을 만들 수도 있다.

예시 코드:

using System;
using System.IO;
using UnityEngine;

public class FileLogger : MonoBehaviour
{
    string logPath;

    void Awake()
    {
        logPath = Path.Combine(Application.persistentDataPath, "log.txt");
        Application.logMessageReceived += HandleLog;
    }

    void HandleLog(string logString, string stackTrace, LogType type)
    {
        string log = $"{DateTime.Now} [{type}] {logString}\n{stackTrace}\n";
        File.AppendAllText(logPath, log);
    }
}
저장 위치:

Application.persistentDataPath/log.txt
이 파일을 버그 리포트할 때 보내달라고 하면 된다.

3️⃣ 사용자에게 바로 파일 보내게 하기 (실전 방식)
게임 메뉴에 버튼 하나 만들어서

[버그 리포트]
→ 로그파일 열기
→ 로그파일 보내주세요
이렇게 많이 만든다.

Application.OpenURL(Application.persistentDataPath);
그러면 폴더가 바로 열림.

✅ 정리

가장 간단한 방법

1️⃣ 아무것도 안 만들어도
→ Player.log 자동 생성됨

조금 더 친절한 방법

2️⃣ Application.logMessageReceived로
→ log.txt 직접 저장

원하면 유니티에서 실제로 많이 쓰는 "버그 리포트 + 로그 자동 첨부 시스템" 구조도 알려줄게.
(인디 게임에서 진짜 많이 쓰는 방식이라 꽤 유용함)
